# T12 interface assets report

## Status

**PARTIAL — 42 interface images are verified; the five required VFX strips are not ready.** Their generated sheet and one targeted repair retain near-opaque tinted bands. To avoid shipping a false-transparent effect or substituting a shared icon, all five VFX keys are absent from the runtime manifest. The current manifest is intentionally incomplete and will not satisfy the existing interface-pack required-key check until these assets are repaired.

## Delivered files

- `public/assets/interface/manifest.json` — 42 unique image keys and relative URLs.
- `public/assets/interface/` — 42 runtime PNGs; combined size **1,170,302 bytes (1.12 MiB / under the 6 MiB budget)**.
- `art-source/interface/` — six generated source sheets, one accepted UI skin repair, one rejected VFX repair, full prompt/reference log, deterministic crop/downsample script, and 32px review sheet.

Image icons are individual 128×128 RGBA PNGs with `displayWidth` / `displayHeight` 32×32. Markers are likewise 128×128 and displayed at 32×32. The UI pieces use separate PNGs and declared display sizes: panel 224×224, buttons and bars 192×60, slots 48×48. The initial UI skin sheet had a panel crossing a cell boundary; its one targeted repair produced a fully contained frame, and the runtime crops use that repaired sheet. Runtime PNGs preserve source alpha; the crop script only crops cells, trims transparent margins for UI pieces, resamples, and re-encodes.
