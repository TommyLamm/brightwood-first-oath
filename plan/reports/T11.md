## Layout and source files

- Theme layers are single images for the 960×540 scene. Apply scroll factors sky `0`, far `.2`, mid `.5`; sky sources are opaque RGB, while far/mid preserve alpha. Layer borders have not been proven pixel-perfect seamless; overlap them when repeating.
- Standalone props use one frame each. Pivots: theme layers `(0,0)`, ladder `(.5,.5)`, other props `(.5,1)`.
- All accepted runtime images have corresponding original generation output copies in `art-source/environment/`. Generation tool, references, output paths, dimensions, hashes, alpha/seam checks, and known issues are recorded in `art-source/environment/source-log.md`; prompt text unavailable in retained history is explicitly marked unavailable rather than reconstructed. New formal outputs used the local protagonist reference `art-source/actors/hero-style-reference-v1.png` and the local forest style image.
- `forest-style-reference-v1.png`, rejected platform/slope candidates, and previews remain source-only. The accepted ground source is copied unchanged to runtime; no image processing or pixel repair was used.
