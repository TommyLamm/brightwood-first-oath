## Layout and source files

- Theme layers are single images for the 960×540 scene. Apply scroll factors sky `0`, far `.2`, mid `.5`; sky sources are opaque RGB, while far/mid preserve alpha. Layer borders have not been proven pixel-perfect seamless; overlap them when repeating.
- Standalone props use one frame each. Pivots: theme layers `(0,0)`, ladder `(.5,.5)`, other props `(.5,1)`.
- All accepted runtime images have corresponding original generation output copies in `art-source/environment/`. Full prompts, generation tool, explicit local references, output paths, source/runtime dimensions, transforms, hashes, alpha samples and known issues are logged in `art-source/environment/source-log.md`. New formal outputs used the local protagonist reference `art-source/actors/hero-style-reference-v1.png` and the local forest style image. The historic slope-correction prompt was not available in the resumed context and is explicitly marked unavailable rather than reconstructed.
- `forest-style-reference-v1.png` and all unaccepted terrain candidates/previews remain source-only; no reference or candidate texture is shipped in runtime.
