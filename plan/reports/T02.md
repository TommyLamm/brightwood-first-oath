## 公開介面與接線

`src/domain/movement/index.ts` 匯出：

```ts
createMovement(position: Vec2): MovementState
stepMovement(
  state: MovementState,
  input: InputFrame,
  map: MapDef,
  config: MovementConfig,
  dtSeconds: number,
  nowMs: number,
): MovementState
```

型別直接引用 T00 contracts。最小接線例子（app 每個固定 tick 擷取一次輸入）：

```ts
import { createMovement, stepMovement } from '../domain/movement/index.js';
import type { InputFrame, MapDef, MovementConfig } from '../contracts/index.js';

let movement = createMovement(spawnPosition);
const input: InputFrame = readMovementInput();
const movementConfig: MovementConfig = rulesCatalog.movement;
movement = stepMovement(movement, input, currentMap, movementConfig, 1 / 60, gameTimeMs);
```

攻擊中要減速時，app 複製 config 並下調 `speed` 後傳入，不改 movement 狀態或查技能資料。T06 可用相同介面移動怪物，按怪物速度傳入 `config`。

## 行為與容許誤差

- `createMovement` 建 airborne、零速、面右、沒有 foothold/ladder；dead 狀態回傳位置及速度相同的複本。
- Grounded 才接受 jump；普通地面放開方向立即停止，空中同樣可水平操控。`nowMs < knockbackUntilMs` 時保留既有水平速度，垂直重力持續。
- 重力按 dt 更新並受 terminal velocity 限制；下降時以左右腳底掃描線段與地形求最早接觸，落在斜坡的線性插值高度。從下方上穿單向平台不碰撞；單向平台不作天花板。
- 地面沿支援 foothold 更新高度；相鄰 foothold 要與舊腳底在端點相接才轉移，端點垂直容差 3 px，避免吸附高平台。落下期間不保持舊 foothold。
- `walls` 阻擋水平穿越與向上頭頂碰撞；世界左右邊界依碰撞體半寬限制。超出 `map.height + 100` 後重置到 `left` spawn（若地圖未提供則取第一 spawn）。
- 下＋jump 只對 `dropThrough: true` foothold 生效，設 `dropThroughUntilMs = nowMs + 300`、向下推 80 px/s，當步跳過該 foothold；主地面仍正常跳躍。落地時仍會選取下方較早接觸的合法地形。
- 上／下輸入在水平距 ladder 不超過 16 px 且垂直範圍相交時吸附梯繩；爬速直接使用 config，停爬凍結，跳躍可離梯；抵達梯頂／底可接上端或底端 ±3 px 內 foothold。
- 上述容差以世界 px 計；運動結果只隨固定 `dtSeconds` 和傳入 game clock 變化，不使用顯示 FPS 或牆上時鐘。

## 七地圖主線移動量算（2026-10-18）

- 實際規則常數：`speed=140 px/s`、`climbSpeed=90 px/s`、`gravity=1600 px/s²`、`jumpVelocity=-520 px/s`、`terminalVelocity=900 px/s`、碰撞體 24×44 px。理想單跳最高約 `520²/(2×1600)=84.5 px`，不含離散 tick 誤差。
- 七圖向前走訪（camp 起點 x=150 到營地出口，再依序從左出生點走到各出口；祭壇從 entry x=160 到首領 x=1000）共 `1,190+1,720+1,720+1,960+1,960+1,720+840=11,110 px`，按 140 px/s 約 79.4 秒。
- 代表任務路線加上必要交接往返，並使用目前 app 已有的 `returnTown` 捷徑完成 q03、q04 回城：camp 教學／q01 2,790 px；q02 鎮內 600；q03 2,930；q04 3,450；前往赤岩 keeper 4,950；q05、q06 在赤岩往返三個野豬區各一次共 4,200；q07 keeper→礦口、四個敵區與回 keeper 6,620；q08 keeper→祭壇首領及原路回 keeper 8,800。合計 `34,340 px ÷ 140 = 245.3 秒`，約 4 分 5 秒無阻走路。
- 這個數字只量走路距離，不含戰鬥、對話／選單、拾取、重生等待、攻擊時 25% 移速、受擊擊退或切圖載入；亦不把擊殺數換算成可預測的移動量。若 q03、q04 不使用 `returnTown` 而步行回鎮，代表路線另增加約 5,340 px／38 秒。故 4 分 5 秒是代表性走路估值，不是主線總遊玩時間承諾。
- 正式七圖的主線 NPC、怪物、傳點及首領位置均在 y=600 主地面；地面由 x=0 延伸至地圖寬度。核心目標無須上平台或爬梯；平台／梯繩是可選地形，不形成主線的垂直必經路段。地面速度與連續輸入直接相符，路線以 45–60 分鐘總主線時間計僅約 6.8–9.1% 純移動，符合加速跑圖方向；本次未發現可在 T02 內修正、且會嚴重拖慢核心路線的移動缺陷。
