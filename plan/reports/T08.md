## Implementation

Added `src/ui/index.ts` and `src/ui/styles.css`. Public entry point:

```ts
createUi(root: HTMLElement, dispatch: (command: CommandDraft) => void): UiController
```

The controller provides `render`, `setPanel`, `isInputCaptured`, and `dispose`. One delegated listener set handles UI actions; `dispose` removes it. Rendering uses DOM text nodes / `textContent`, preserves active input focus, and does not write to localStorage.

The package now includes title/continue/create flows with two-step replacement confirmation, loading/error/pause/death/result views, status HUD and quick slots, 32-slot filtered inventory with item details and use/equip/sell actions, three equipment slots and unequip, stat allocation, five learnable skills with rank/SP requirements, quest groups and NPC dialogue actions, quantity-based shop buy/sell, seven-area map and portal requirements, audio/control settings, and explicit save/conflict/error states. No drag interaction or new content was added.

UI command dispatch points cover: `setPanel`, `closePanel`, `continue`, `newGame`, `returnTitle`, `retrySave`, `playTemporary`, `togglePause`, `respawn`, `retryBoss`, `returnTown`, `attack`, `pickup`, `interact`, `useItem`, `equip`, `sell`, `unequip`, `allocateAp`, `learnSkill`, `acceptQuest`, `claimQuest`, `buy`, `setSettings`, and `useCloudVersion`. All commands omit `seq` for the app dispatcher to assign.

## T08-08 returnTown closure and app gate evidence

- `UiSnapshot.canReturnTown` already supplies the required signal; no shared contract change was needed. The HUD, result screen, and map-panel return controls use this field for their disabled state. The delegated `return-town` handler also returns without dispatching when `view.canReturnTown` is false. The HUD control is hidden outside active play; this does not add a second return-permission rule.
- The map panel renders a visible disabled explanation for the arena: `首領戰中無法回城；請先結束挑戰。` Its button title also says `首領戰尚未結束，不能返回城鎮。`
- Current app code confirms the corresponding lifecycle: `src/app/state.ts:createUiSnapshot` allows return when gameplay exists, the map is not town, the screen is `playing` or `result`, and either the map is not `guardian-arena` or `gameplay.bossResult` is true. `src/app/app.ts` passes `returnTown` through on `playing` and `result`; `src/app/gameplay.ts` rejects the arena command before `bossResult` with the same disabled reason, then transitions to town otherwise. `bossResult` on `playing` changes the screen to `result`.
- This replaces the prior T14 return-town blocker note. `src/main.ts` still imports `createAppUi` from `src/app/root-ui.ts`; T14 owns switching to `createUi` and passing the app dispatcher, while T16 owns final integration validation. This package does not edit app files.
