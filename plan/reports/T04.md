## app 接線例與錯誤處理

```ts
const checkedName = validatePlayerName(inputName);
if (!checkedName.ok) return showError(checkedName.message);
let player = createPlayer(checkedName.value, rulesCatalog);

const rewardResult = applyProgressAction(player, {
  type: 'gainReward',
  reward: { exp: 60, coins: 80, items: [{ itemId: 'small-red', quantity: 5 }] },
}, rulesCatalog);
if (rewardResult.ok) player = rewardResult.value;
else showError(rewardResult.message); // 例如背包不足回 BAG_FULL

const equipped = applyProgressAction(player, { type: 'equip', bagIndex: currentBagIndex }, rulesCatalog);
if (equipped.ok) player = equipped.value;
else showError(equipped.message); // 卸裝無空格回 { ok:false, code:'BAG_FULL', ... }
```

bagIndex 是目前 snapshot 的索引；app 執行命令時要對最新 player 呼叫 domain 並顯示錯誤。q02 領獎由 app/T05 先 `setLevelFloor(10)` 再 `changeJob`，只有所有操作成功後才提交玩家與任務狀態。MP 攻擊成本需與 combat 交易一起提交；guard 有效期間由 app 對即時 stats 加成，不寫入存檔。藥水冷卻、休息回復時間、商店 DOM、掉落生成、死亡傳送、存檔均不屬於 T04。
