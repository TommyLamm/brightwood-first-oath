## 接線方式與狀態語意

```ts
const persistence = createPersistence({
  gameId: 'maplewood-swordsman',
  storage: injectedStorageLike,
  cloud: injectedCloudPort, // 尚待 T15 正式 adapter
  catalog: { rules: rulesCatalog, world: worldCatalog },
  onStatus: (status, message) => updateSaveIndicator(status, message),
});

const loaded = await persistence.initialize();
// 僅 loaded.status 為 ready/localSaved/previewOnly 之成功初始化路徑可套用 data。
// app 必須將 arena 的遊玩位置轉成 mine-gate/right 後再載入；本包 validator 不改主線資料。
persistence.checkpoint(nextSaveData);
```

- `ready` / `loading` / `saving`：初始化成功、讀取中、寫入中。
- `saved`：CloudPort 回應確認 `saved:true`，已採用回傳 revision。
- `localSaved`：本機 `setItem` 完成。
- `previewOnly`：預覽診斷連線或寫入；不表示正式雲端持久化。
- `unavailable`：無正式雲端保存或無本機 storage；不自動換另一種存放方式。
- `loadError`：讀取／解析／資料驗證失敗；舊本機 bytes 保留，應修復連線後重新 `initialize()`。
- `saveError`：可呼叫 `retry()`；雲端重送原快照及同 requestId，local 重試固定快照。
- `conflict`：不要自動重送；呼叫 `initialize()` 載入最新雲端版本後再由 app 決定。
- `authLost` / `incompatible`：停止佇列並由 app 顯示重新驗證／版本相容處理。

呼叫端離開或重載持久化 session 時先 `invalidate()`；同一 session 只返回 title 時保留排隊中的 checkpoint。暫時遊玩不應把訪客資料匯入雲端。cloud load 失敗只回傳 memory/loadError，app 可另建立暫時角色供離線操作，但不可呼叫本 persistence 寫入初始資料。T15 尚未提供正式 adapter，本包沒有真實帳號雲存檔驗證；fake CloudPort 只能驗證本地狀態機。
