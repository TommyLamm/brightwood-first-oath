## Public API and caller example

Exports from src/render/index.ts:

- RendererAssetError — carries code = RENDER_ASSET_ERROR and an implicated assetKeys list.
- createWorldRenderer(scene, assetManifests, catalog, heroAnchors?): WorldRenderer — returns loadMap(map), render(snapshot), resize(width, height), and dispose(). The formal app passes the separately loaded `assets/actors/anchors.json` as the fourth argument.

~~~ts
const renderer = createWorldRenderer(scene, manifests, catalog, heroAnchors);

try {
  await renderer.loadMap(targetMap);
  // The app commits the new map/world only after this resolves.
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  showMapLoadError(message, () => renderer.loadMap(targetMap));
  // A failed candidate load leaves the active map available.
}

renderer.render(worldSnapshot); // includes questViews; after app snapshot commit
renderer.resize(viewWidth, viewHeight); // viewport changes
renderer.dispose(); // Scene teardown
~~~

The Scene Loader must be idle before loading starts; a concurrent loader use fails with a retryable error. WorldSnapshot.mapId must match the successfully loaded map. The renderer reads catalog names and dimensions, but does not grant rewards or mutate domain state.
