## 為消除猜測採用的固定預設

以下是交接執行預設，不冒稱使用者親自指定：

- 工作名稱「楓境冒險：劍士篇」，候選固定 ID maplewood-swordsman，開發 0.1.0、候選 1.0.0-beta.1、正式 1.0.0。若開工已有正式 ID，由主 Agent 保留並統一調整。
- 作者暫填「獨立製作」，發布前可按使用者署名調整，不虛構工作室。
- 原創內容命名、繁體中文、經典比例與節拍；自行生成圖片及自行合成音訊。
- 單角色名稱 1–12 個 Unicode 字素，去空白／控制字元，用 textContent 顯示。無性別、髮型、臉型選擇。
- 1–30 級；兩攻擊、一增益、兩被動，詳見 08；不是原版完整技能表逐項復刻。
- 無死亡懲罰、無洗點／強化／耐久／交易／倉庫／排行榜。
- 視口 960×540、最低 iframe 640×360，正常場景目標 60 FPS；只報實際環境證據。

## 風險處置

| 風險 | 固定處理 |
| --- | --- |
| 契約分歧 | T00 先發布實際 contracts，只有主 Agent 修改並通知消費者 |
| 動畫不連貫 | 固定主角參考、分狀態生成、統一錨點；只修失敗組 |
| 地圖不可玩 | 先固定碰撞線段，背景不能決定碰撞 |
| 成長太快／慢 | 初始表在 08，由 T01／主 Agent 集中校正並記偏差 |
| 存檔覆蓋 | T09 先讀後寫、序列快照、revision/requestId、過期回應 token |
| 檔案與建置衝突 | 09 固定所有權與單一 build 執行者 |
| 工具共享狀態 | 明確本地參考路徑，必要時主 Agent 單一圖片佇列 |
| 規格／網路失敗 | 報實際 URL 與原因，繼續不依賴缺項的工作，不假報通過 |
| 素材過大 | 內部 ZIP 預算 48 MiB，按包控制，不暗改必要外鏈 |

新需求與必要整合修正由主 Agent 記錄；子代理不得單方面改產品方向。
