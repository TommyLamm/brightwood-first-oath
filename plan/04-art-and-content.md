# 素材與內容製作原則

使用者已選 Agent 自行生成。依 imagegen 技能使用內建圖片生成／編輯工具；本輪不生成圖片。T10 擁有角色／敵人／NPC，T11 擁有環境，T12 擁有圖示／UI 皮膚／特效，T13 自行合成音訊。輸出契約見 [10](10-asset-spec.md)。

每包先固定風格樣板再沿同一參考製作，角色腳底、握點、圖層與畫格時長配合程式規則。透明素材必須是真 alpha。入遊戲資產複製進專案所屬目錄，記錄 prompt、工具、參考、輸出、尺寸與版本。

子代理只改自己的 manifest，主 Agent 聚合。編輯本地參考圖先查看，再用明確本地路徑指定，避免共享對話圖片順序。若子代理工具受限，由主 Agent 集中處理明確 prompt 清單，其他代理繼續 metadata；不創建新的使用者聊天。

生成失敗可保留標示清楚的開發占位，但不能以 CSS 幾何人物代替正式點陣角色並標完成。UI 文字使用 HTML／Canvas 正規文字，不烘焙到圖片。音效／音樂自行合成，不宣稱 ImageGen 生成音訊。

內容 ID 以 [08](08-content-spec.md) 為準，不自行增加怪物、地圖或職業。T15 從實際遊戲畫面製作封面，不能用概念圖冒充截圖。
