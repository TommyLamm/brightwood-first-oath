# 首版遊戲設計：已定案

## 範圍與流程

台港大改版前冒險者風格，初心者至一轉劍士，1–30 級、45–60 分鐘主線、單機單角色、桌面鍵盤滑鼠。固定七地圖、六普通怪、一名兩階段首領、五 NPC、八主線任務、24 物品。ID、位置、數值與獎勵以 [08](08-content-spec.md) 為唯一來源。

標題／建立角色 → 教學 → 城鎮 → 轉職 → 擊殺／收集 → 升級／配點／技能 → 補給／換裝 → 新區域 → 首領 → 結算 → 繼續或重試。結算不刪存檔，新角色須明確確認。

## 操作與節奏

方向鍵走路／攀爬，Alt 跳、下＋Alt 下跳、Ctrl 普攻、Z 拾取、Space 互動、1／2／3 技能、Q／W 藥水、I 背包、E 裝備、K 技能、C 能力、J 任務、M 地圖、Esc 關最上層面板或暫停。可改鍵；失焦清空輸入，只在遊戲聚焦且非文字輸入時防止瀏覽器預設行為。

保留單跳、斜坡、單向平台、梯繩及近戰前後搖，無雙跳／衝刺／自動戰鬥。以短地圖、已訪城鎮快捷回返及就近交任務加快跑圖，不暴增移速。按住 Z 每 150ms 撿附近一件。

地面與空中可攻擊，出手期間鎖面向、水平移速降至 25%，垂直物理繼續，不取消前後搖。接觸傷害無敵 800ms。失焦／暫停／設定凍結時間；背包與任務面板不凍結戰鬥。

死亡不扣經驗／金錢，回城恢復 HP／MP。主線道具在任務進行時必掉，普通裝備隨機掉落。無耐久、洗點、強化、倉庫、排行榜。數值為專案加速曲線，不聲稱原版內部公式。

## 視覺與邊界

參考同時期操作節拍與比例，自行生成角色、地圖、圖示及特效，自行合成音訊。以原創內容名稱呈現經典世界風格。武器、衣服、帽子三槽換裝有可見差異，無額外臉型／髮型選擇。資產規格見 [10](10-asset-spec.md)。

其他職業、二轉、手機、手把、多角色、真正多人、交易、公會與付費都在首版外。多人只保留穩定 ID、命令、純邏輯及快照接口。

完成必須包含完整主線、死亡復活、結算重試、重開恢復、正式素材、靜態候選與必要 iframe／SDK 驗收；程式、ZIP、Release、上架分開報告。
